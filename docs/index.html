Creator workflow · Operated by Wardiyan

From selected products to approved Pins.

PinShop helps a creator prepare original product creative, review the batch, choose Pins to publish—including select all—and confirm once.

API access preparation

Built for a single authenticated account owner. No Pinterest passwords, session cookies, engagement automation, or Pinterest scraping.

Human-controlled publishing

Every publication stays intentional.

The app prepares drafts from Shopee Affiliate products matching the creator's filters. The creator remains responsible for rights, affiliate disclosure, destination board, and the final publish decision.

STEP 01

Filter

The creator sets a Shopee Affiliate category, optional keywords, destination Board, and batch size.

STEP 02

Review

The app shows every draft's image, title, description, affiliate link, and Board in one list. The creator may select all or choose particular Pins; full-size details and edits remain available.

STEP 03

Approve

One explicit confirmation starts publishing only the selected Pins through Pinterest API v5 on the creator's own account.

Least-privilege access

Only the permissions needed to publish.

PinShop requests boards:read, boards:write, pins:read, and pins:write. These permissions are used only to show the owner's boards, create a board when the owner asks, publish an approved Pin, and confirm the result.

Pinterest data is not sold, shared for advertising, combined across users, used for engagement automation, or used to train AI models.
