Creator workflow · Operated by Wardiyan

From selected products to approved Pins.

AutoPin Shopee helps a creator prepare original product creative, review every draft, individually choose each Pin to publish, and confirm the selected batch once.

API access preparation

Built for a single authenticated account owner. No Pinterest passwords, session cookies, engagement automation, or Pinterest scraping.

Human-controlled publishing

Every publication stays intentional.

The app prepares drafts from products the creator has already selected. The creator remains responsible for rights, affiliate disclosure, destination board, timing, and the final publish decision.

STEP 01

Select

The creator selects eligible Shopee Affiliate products and source imagery they are authorised to promote.

STEP 02

Review

The app shows every draft's image, title, description, affiliate link, and board in one list. The creator chooses each Pin individually; full-size details and edits remain available.

STEP 03

Approve

One confirmation starts publishing only the individually selected Pins through Pinterest API v5 on the creator's own account.

Least-privilege access

Only the permissions needed to publish.

AutoPin Shopee requests boards:read, boards:write, pins:read, and pins:write. These permissions are used only to show the owner's boards, create a board when the owner asks, publish an approved Pin, and confirm the result.

Pinterest data is not sold, shared for advertising, combined across users, used for engagement automation, or used to train AI models.
