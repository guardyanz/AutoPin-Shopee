Data Deletion Instructions

You can disconnect Pinterest and remove PinShop data without contacting us.

1. Revoke Pinterest access

Open your Pinterest account settings, locate connected apps or app permissions, and revoke PinShop. Revocation prevents future API calls with that authorisation.

2. Remove local extension data

  1. Open chrome://extensions.
  2. Locate PinShop.
  3. Select Remove and confirm.
  4. To keep the extension but reset it, use the app's disconnect/reset control when available, or clear the extension's site data from Chrome settings.

This removes locally stored settings, product drafts, activity records, publication history, and locally held credentials from that Chrome profile.

3. Request assistance

If the OAuth callback service holds an active short-lived transaction or you need help confirming deletion, email akurindowijayapwt@gmail.com with the subject “PinShop data deletion”. Do not send passwords, access tokens, refresh tokens, client secrets, or session cookies.

Expected timing

Local deletion is immediate. Valid server-side deletion requests are completed within 30 days unless a shorter period is required by law. Security logs required to protect the service may be retained for a limited period and then deleted or de-identified.
