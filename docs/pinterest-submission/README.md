# Pinterest API application pack

Use the files in this directory in this order:

1. `FORM-ANSWERS.md` — exact Trial application values and checkbox choices.
2. `SUBMISSION-CHECKLIST.md` — pre-submit validation and the path from Trial to Standard.
3. `OAUTH-AND-SCOPES.md` — least-privilege permissions, endpoints, and redirect URI rules.
4. `SECURITY-DATA-FLOW.md` — reviewer-friendly security and data-use explanation.
5. `STANDARD-ACCESS-VIDEO-SCRIPT.md` — required live OAuth/API demo for the later Standard upgrade.
6. `assets/` — application icon PNGs ready for upload.
